# Предиктивный ввод с локальной моделью

В подробных настройках Keyboop откройте «Предиктивный ввод». Включите «Завершение слов» или «Следующее слово». Поле «Попробовать» использует обычное событие клавиатуры, считывание каретки через Accessibility и настроенное сочетание принятия.

## Локальная модель

Включите «Локальная ИИ-модель» и нажмите «Скачать». Для новой установки по умолчанию выбраны встроенный llama.cpp и Qwen3-0.6B-Base Q4_K_M (397 МБ). Выбор модели сохраняется, также доступна Qwen3.5-0.8B-Base Q4_K_M (529 МБ). После проверки размера и SHA-256 Keyboop запускает отдельный процесс llama.cpp с Metal на Apple Silicon. Статус показывает загрузку, проверку, запуск и готовность. Скачивание можно отменить, установленную модель можно удалить. Встроенный процесс освобождает модель после двух минут простоя и при давлении на память.

Для пользователей ранее настроенного сервера сохранён внешний режим на 127.0.0.1:18181. Новый управляемый процесс использует свободный локальный порт и одноразовый ключ. Веса остаются на диске между запусками. Кнопка «Проверить модель» отправляет фиксированную фразу и показывает продолжение вместе со временем до первого слова. Для этой проверки достаточно запущенного локального движка.

## Поведение при наборе

- После 120 мс паузы Keyboop сначала ищет завершение или следующее слово в локальном словаре. При промахе запрашивает модель. На модель выделено до 650 мс после подготовки контекста.
- Запрос содержит до 128 единиц UTF-16 перед кареткой. Для недописанного слова модель обязана воспроизвести префикс, и в подсказку попадают только новые буквы. На границе слов допустимы переходы между русским и английским.
- Встроенный llama.cpp повторно использует KV-кэш в последовательных запросах из одного поля. После смены поля первый запрос начинает расчёт заново. Для длинного текста начало окна контекста сдвигается шагами по 32 единицы UTF-16, чтобы при дописывании сохранялась общая часть. Новый ввод сразу отменяет предыдущий потоковый HTTP-запрос.
- Первый уверенный фрагмент появляется по мере ответа сервера. Продолжение ограничено тремя словами. Нажатие сочетания завершает текущее слово или вставляет следующее слово, а затем добавляет пробел. Остаток подсказки начинается после этого пробела. Пока пользователь пишет совпадающие буквы, Keyboop сокращает подсказку после сверки с текстом поля.
- При смене поля, перемещении каретки или расхождении с предложением предыдущий результат отбрасывается. Перед вставкой Keyboop повторно проверяет поле и его содержимое. Защищённый ввод и исключения действуют для обоих источников.
- Серый текст отрисовывается у каретки в свободном месте строки. Если справа уже есть текст, в настройках показывается причина пропуска. В многострочном поле Keyboop сверяет координаты каретки с последним набранным символом. Для текстового узла веб-редактора можно использовать границы последнего символа или последней визуальной строки. При переносе, прокрутке или изменении высоты поля уже показанная подсказка следует за кареткой, пока поле, текст и позиция ввода совпадают.
- Диагностика показывает причину последнего результата без содержимого поля. Для проверки словарного пути наберите «до сих» и пробел. Словарь предлагает «пор».

## Измерения

Нажмите «Сравнить на 38 примерах», чтобы сопоставить словарь, прямой запрос и потоковый запрос с ограничением по префиксу на одинаковом наборе русских, английских и смешанных фраз. Для сверки двух моделей прогоняют один и тот же набор с каждым GGUF. Экран показывает количество подсказок, точных совпадений первого слова и p95 времени до первого пригодного слова.

Стенд `tools/benchmark-prediction` использует тот же код и набор из `Sources/Keyboop/Resources/prediction_benchmark.json`. В командной строке доступны дополнительные показатели по языкам и потенциальной экономии нажатий. Задержку от физической клавиши до появления текста и расход батареи измеряют отдельно в живом редакторе.

### Результат от 18 ноября 2026

Прогон из окна настроек Keyboop 0.5.4 на Apple Silicon, со встроенным llama.cpp и GGUF Q4_K_M. Каждому прогону модели предшествовал один запрос «Проверить модель». Пауза ввода 120 мс, чтение каретки и отрисовка подсказки в p95 ниже не входят.

| Модель и режим | Показано из 38 | Совпало первое слово или окончание | p95 первого результата | Ошибки сервера |
| --- | ---: | ---: | ---: | ---: |
| Словарь | 26 | 12 | <1 мс | 0 |
| Qwen3-0.6B, прямой запрос | 14 | 5 | 197 мс | 0 |
| Qwen3-0.6B, с ограничениями | 23 | 17 | 88 мс | 0 |
| Qwen3.5-0.8B, прямой запрос | 17 | 3 | 96 мс | 0 |
| Qwen3.5-0.8B, с ограничениями | 21 | 12 | 115 мс | 0 |

На этом наборе меньшая Qwen с ограничениями дала 17 точных совпадений из 23 показов. Модель оценивалась на каждом примере, в том числе когда ответ уже был в словаре. Для оценки того, сколько дополнительных совпадений получает пользователь в ежедневном наборе, нужен отдельный замер комбинации «словарь → модель при промахе».

Оба GGUF были скачаны через настройки. Контрольные суммы совпали с каталогом, обе модели продолжили «Спасибо за обратную » словом «связь». После двух минут простоя Qwen3-0.6B перешла в состояние ожидания. Повторная проверка показала запуск движка и снова вернула «связь».

## Какие решения пригодились Keyboop

| Проект | Идея | Применение в Keyboop |
| --- | --- | --- |
| [GhostType](https://github.com/mk668a/GhostType) | Локальный llama.cpp с грамматикой GBNF | Генерация обязана воспроизвести набранный префикс, длина продолжения ограничена тремя словами. Вставку между двумя фрагментами текста можно исследовать отдельно. |
| [KeyType](https://github.com/johnbean393/KeyType) | Отдельные компоненты для снимка активного поля через Accessibility, генерации и вставки | Keyboop сверяет приложение, поле и каретку перед показом и перед вставкой. Потоковый клиент тестируется отдельно от редактора. |
| [TabType](https://github.com/nilava/TabType) | Разные пороги уверенности для окончания слова и для следующего слова | В Keyboop для окончания слова порог ниже. Подбор модели и проверка порогов опираются на один русский, английский и смешанный набор. |
| [Cotabby](https://github.com/FuJacob/cotabby) | Принятие фразы по одному слову | Настроенное сочетание добавляет одно слово. Остаток виден у каретки и сокращается при совпадающем наборе. |

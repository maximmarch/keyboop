# Keyboop

**Переключение раскладки, подсказки при наборе и локальная диктовка для macOS.**

[Сборки на GitHub](https://github.com/maximmarch/keyboop/releases) · [История изменений](CHANGELOG.md) · [Сборка из исходников](docs/building.md)

## Возможности

- **Раскладка и исправление набора.** Keyboop распознаёт ошибочную раскладку, исправляет опечатки и позволяет преобразовать недавно введённый текст горячей клавишей.
- **Локальная диктовка.** Распознавание речи через `transcribe.cpp`, предварительный текст во время записи, контекстные профили приложений и зашифрованная история.
- **Коррекция русской диктовки.** SAGE Distilled 95M исправляет орфографию, пунктуацию и грамматику перед вставкой. Проверка запускается после загрузки модели и управляется отдельным переключателем.
- **Подсказки на русском и английском.** Keyboop завершает текущее слово или предлагает следующее. Для словаря можно использовать глоссарий, текст текущего поля и локальную историю принятия. Опциональная Qwen продолжает фразу при промахе словаря. Подсказки принимаются по `⌥Tab` по умолчанию. Обычный `Tab` можно назначить в настройках.
- **Сниппеты, типографика и правила сайтов.** Динамические шаблоны, кавычки и пробелы по правилам типографики, отдельные параметры ввода для доменов Chrome.

## Быстрый старт

1. Откройте [GitHub Releases](https://github.com/maximmarch/keyboop/releases) или [соберите приложение](docs/building.md).
2. При первом запуске выдайте доступ к универсальному доступу и мониторингу ввода. Для диктовки macOS отдельно запрашивает доступ к микрофону.
3. Откройте **Настройки → Модели**. Скачайте модель распознавания речи, например GigaAM v3 для русского, или выберите одну из уже загруженных.
4. Скачайте **SAGE Distilled 95M** в разделе **Модели → Коррекция текста**. Переключатель **Исправлять текст диктовки** доступен там же и в **Голосовой набор → Коррекция текста**.

## Модели

| Задача | Что доступно в Keyboop |
|---|---|
| Распознавание речи | Включение диктовки, выбор, скачивание и удаление моделей каталога `transcribe.cpp` |
| Коррекция текста | Скачивание и удаление SAGE Distilled 95M, включение модели, режим проверки при наборе и отдельный переключатель для диктовки |
| Подсказки при наборе | Включение локальной модели, выбор, скачивание, импорт GGUF и удаление Qwen3-0.6B-Base и Qwen3.5-0.8B-Base |
| Дополнительная постобработка | Apple Intelligence, встроенный llama.cpp с Gemma 4 E2B IT по умолчанию и двумя вариантами Qwen2.5 Instruct, или свой OpenAI-совместимый сервер. GGUF можно скачать, импортировать и удалить в разделе «Модели» или «Голосовой ввод» |

SAGE работает на этом Mac. Если модель не готова или правка выходит за лимит ожидания, Keyboop использует распознанный текст и уже проверенные исправления. Дополнительную постобработку можно включить в настройках голосового ввода. Для встроенной Gemma 4 E2B IT выберите «Встроенный llama.cpp» и скачайте модель или импортируйте `gemma-4-E2B-it-Q4_K_M.gguf`. При выборе собственного сервера ему передаётся текст для обработки.

В обоих разделах со встроенным llama.cpp можно импортировать собственную однофайловую модель через **Импортировать GGUF…**. Установленная модель доступна в обоих списках, а каждый режим запоминает собственный выбор. Удаление убирает веса из общего каталога Keyboop. Совместимость весов проверяет llama.cpp при запуске.

Пилот подсказок внутри предложения запускается для встроенных моделей после проверки качества. [Измерения подсказок](Tests/PredictionEval/README.md)

## Системные требования

- **Apple Silicon** — macOS 14 или новее. Распознавание речи может использовать Metal.
- **Intel x86_64** — macOS 13 или новее. Распознавание речи выполняется на CPU с AVX2.
- Для Apple Intelligence требуется совместимый Mac с включённой системной моделью.

## Данные и приватность

Встроенные модели распознавания, подсказок и коррекции обрабатывают текст и звук локально. Сетевой доступ используется для загрузки весов и обновления каталога. Скопированные данные в историю больше не записываются. Ранее сохранённые записи буфера можно [экспортировать](docs/migrations/clipboard-transfer.md). Совместимый пользовательский сервер постобработки получает текст только при выборе этого провайдера и запуске обработки.

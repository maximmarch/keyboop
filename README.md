# Keyboop

**Переключение раскладки, подсказки при наборе и локальная диктовка для macOS.**

[Сборки на GitHub](https://github.com/maximmarch/keyboop/releases) · [История изменений](CHANGELOG.md) · [Сборка из исходников](docs/building.md)

**Версия 0.6.2.** Глоссарий и настройки предиктивного ввода синхронизируются между своими Mac через выбранную общую папку. Обмен выученными сочетаниями включается отдельно.

## Возможности

- **Раскладка и исправление набора.** Keyboop распознаёт ошибочную раскладку, исправляет опечатки и позволяет преобразовать недавно введённый текст горячей клавишей.
- **Локальная диктовка.** Распознавание речи через `transcribe.cpp`, предварительный текст во время записи, контекстные профили приложений и зашифрованная история.
- **Коррекция русской диктовки.** SAGE Distilled 95M исправляет орфографию, пунктуацию и грамматику перед вставкой. Проверка запускается после загрузки модели и управляется отдельным переключателем.
- **Подсказки на русском и английском.** Keyboop завершает текущее слово или предлагает следующее. Можно использовать глоссарий, текст текущего поля и локальную историю принятия. Когда в словаре нет варианта, приложение может обратиться к локальной модели. По умолчанию подсказки принимаются по `⌥Tab`. Обычный `Tab` можно назначить в настройках.
- **Сниппеты, типографика и правила сайтов.** Сокращения разворачиваются выбранными клавишами `Space`, `Enter` или `Tab`. Правила кавычек, тире и пробелов можно проверить в разделе **Типографика → Попробовать**. Для доменов Chrome доступны отдельные параметры ввода.

При быстром наборе Keyboop сверяет готовую подсказку с тем, что вы уже напечатали, и показывает оставшиеся буквы. Если включено **Следующее слово**, во время показа фразы словарь подбирает её продолжение. После принятия последнего слова Keyboop сразу проверяет продолжение в том же поле.

В **Настройки → Предиктивный ввод → Польза подсказок** видны показы, доля принятых подсказок, быстрые отмены, сэкономленные нажатия и средняя задержка. Русский и английский считаются отдельно. Когда на этом Mac появятся данные двух сборок, их можно сравнить рядом. Статистика хранится локально и не содержит набранного текста.

## Быстрый старт

1. Откройте [GitHub Releases](https://github.com/maximmarch/keyboop/releases) или [соберите приложение](docs/building.md).
2. При первом запуске выдайте доступ к универсальному доступу и мониторингу ввода. Для диктовки macOS отдельно запрашивает доступ к микрофону.
3. Откройте **Настройки → Модели**. Скачайте модель распознавания речи, например GigaAM v3 для русского, или выберите одну из уже загруженных.
4. Скачайте **SAGE Distilled 95M** в разделе **Модели → Коррекция текста**. Переключатель **Исправлять текст диктовки** доступен там же и в **Голосовой набор → Коррекция текста**.

## Модели

| Задача | Что доступно в Keyboop |
|---|---|
| Распознавание речи | Включение диктовки, выбор, скачивание и удаление моделей каталога `transcribe.cpp` |
| Коррекция текста | Скачивание и удаление SAGE Distilled 95M, включение модели, режим проверки при наборе и отдельный переключатель для диктовки |
| Подсказки при наборе | Включение локальной модели, выбор, скачивание, импорт GGUF и удаление Qwen3-0.6B-Base и Qwen3.5-0.8B-Base |
| Дополнительная постобработка | Apple Intelligence, встроенный llama.cpp с Gemma 4 E2B IT по умолчанию и двумя вариантами Qwen2.5 Instruct, или свой OpenAI-совместимый сервер. GGUF можно скачать, импортировать и удалить в разделе «Модели» или «Голосовой набор» |

SAGE работает на этом Mac. Если модель не готова или правка выходит за лимит ожидания, Keyboop использует распознанный текст и уже проверенные исправления. Дополнительную постобработку можно включить в настройках голосового ввода. Для встроенной Gemma 4 E2B IT выберите «Встроенный llama.cpp» и скачайте модель или импортируйте `gemma-4-E2B-it-Q4_K_M.gguf`. При выборе собственного сервера ему передаётся текст для обработки.

В **Настройки → Модели** выберите встроенный llama.cpp в блоке предиктивного ввода или постобработки. Нажмите **Импортировать GGUF…** и выберите файл с весами модели. Установленная модель доступна в обоих списках, а каждый режим запоминает собственный выбор. Удаление убирает веса из обоих списков Keyboop. Совместимость весов проверяет llama.cpp при запуске.

Пилот подсказок внутри предложения запускается для встроенных моделей после проверки качества. [Измерения подсказок](Tests/PredictionEval/README.md)

## Системные требования

- **Apple Silicon** — macOS 14 или новее. Распознавание речи может использовать Metal.
- **Intel x86_64** — macOS 13 или новее. Распознавание речи выполняется на CPU с AVX2.
- Для Apple Intelligence требуется совместимый Mac с включённой системной моделью.

## Синхронизация между Mac

В **Настройки → Предиктивный ввод → Синхронизация между Mac** выберите одну и ту же папку в iCloud Drive, другом файловом сервисе или на общем диске на каждом Mac. Используйте личную папку: её участники могут читать и менять переданные данные. Пока Keyboop запущен, он сверяет изменения примерно раз в 20 секунд. Кнопка **Обмен сейчас** запускает сверку сразу. Доставку файлов на другой Mac выполняет выбранный сервис.

Глоссарий объединяется по словам, включая удаления. Отдельно переносятся пять переключателей: завершение слов, следующее слово, подсказки внутри предложения, слова из текущего поля и системная проверка. Для обмена личной лексикой включите обучение и **Также передавать выученные слова и сочетания** на каждом участвующем Mac. Передаются выученные слова, до двух слов контекста и веса для подсказок. При выключении этой опции Keyboop убирает копию данного Mac при следующем обмене. Приостановка всего обмена оставляет уже записанные файлы в папке. Диктовки, переписка, статистика, ключи доступа и файлы моделей в обмен не входят.

## Данные и приватность

Встроенные модели распознавания, подсказок и коррекции обрабатывают текст и звук локально. Сетевой доступ используется для загрузки весов и обновления каталога. Если вы включили синхронизацию, доставку данных между Mac обеспечивает выбранная общая папка. Скопированные данные в историю больше не записываются. Ранее сохранённые записи буфера можно [экспортировать](docs/migrations/clipboard-transfer.md). Совместимый пользовательский сервер постобработки получает текст только при выборе этого провайдера и запуске обработки.
